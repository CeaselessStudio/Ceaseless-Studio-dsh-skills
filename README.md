# dsh-skills

Плагин DeepSeek Harness: кнопка **«Скиллы»** в шапке чата. Открывает каталог
скиллов, которые видит текущая сессия, и позволяет прочитать полный текст
`SKILL.md`, не уходя из диалога.

## Что показывает

| Элемент | Где | Что это |
| --- | --- | --- |
| Кнопка «Скиллы» | шапка чата, слот `conversation.session.header.utilities` | звезда, слово «Скиллы» и число найденных скиллов |
| Поиск | верх поповера | фильтр по имени, описанию и «когда использовать» |
| Группы | внутри поповера | `.dsh/skills`, `.agents/skills`, `.claude/skills`, другие каталоги, встроенные без файла |
| Бейдж строки | справа от имени | `модель` - скилл доступен инструменту `skill`; `только /имя` - вызывается лишь вручную |
| Раскрытие строки | клик по строке | полный текст `SKILL.md` в прокручиваемом блоке |
| «Обновить» | верх поповера | перечитать каталог сразу, не дожидаясь минуты |

## Как устроено

```
client  client.js  →  ctx.remote.skills.list({ sessionId })  →  полный каталог сессии
                   ↘  при ошибке: GET /plugin/skills          →  запасной каталог хоста
                   →  клик по строке: GET /plugin/skills/file?path=   →  текст SKILL.md с диска
                                      GET /plugin/skills/item?name=   →  текст из реестра, если файла нет
host    index.js   →  запасной каталог ctx.skills.list({ cwd }) + чтение файла + ctx.skills.get()
```

Ключевое решение: каталог берётся из RPC `skills/list` для текущей сессии - того
же, что наполняет меню `/` в композере. Он отдаёт ровно те скиллы, что доступны
человеку: файловые из проекта и личных каталогов, встроенные из плагинов, с
учётом области видимости пресета агента.

Почему не через хост целиком: у хоста нет агента, поэтому `ctx.skills.list({ cwd })`
возвращает только глобальный слой - встроенные и плагинные скиллы. Файловые
скиллы живут в области видимости пресета, и без сессии их не достать. Поэтому
хост отвечает только за то, чего браузер не умеет: запасной каталог на случай,
если RPC сессии недоступен (первый кадр после перезагрузки, холодная сессия),
чтение `SKILL.md` с диска и текст скилла из реестра - у встроенных в плагин
скиллов операционного пути нет, файл лежит внутри `assets`, и тело отдаёт сам
провайдер.

## Установка

Пакет - бандл: в `cordis.patch.yml` одна строка загрузчика.

```powershell
git clone https://github.com/CeaselessStudio/dsh-skills ~\.dsh\local-plugins\dsh-skills
cd ~\.dsh\profiles\desktop
pnpm add "link:$HOME\.dsh\local-plugins\dsh-skills"
```

Затем добавьте `@local/dsh-skills` в `dsh.profile.bundles` в
`~/.dsh/profiles/desktop/package.json` и перезапустите DSH. Правки `client.js`
подхватываются перезагрузкой страницы, правки `index.js` - только рестартом
приложения.

Снять: убрать имя из `bundles` и выполнить `pnpm install` заново.

## Настройка

Необязательные ключи строки загрузчика (влияют только на запасной каталог):

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `cwd` | воркспейсы профиля | строка или список каталогов, где искать проектные скиллы |
| `ttlMs` | `30000` | сколько держать кэш запасного каталога, минимум 5000 |

```yaml
- insert:
    - id: skills-panel
      name: '@local/dsh-skills'
      config:
        ttlMs: 60000
```

## Формат ответа

`GET /plugin/skills` - запасной каталог.

```json
{
  "ok": true,
  "fetchedAt": 1793269934399,
  "durationMs": 41,
  "refreshing": false,
  "error": null,
  "data": {
    "generatedAt": "2026-10-30T18:20:00.000Z",
    "ttlMs": 30000,
    "skills": [
      {
        "name": "office-xlsx",
        "description": "Read, create, edit, and validate Excel workbooks…",
        "path": "…\\dsh-skill-office\\assets\\office-xlsx\\SKILL.md",
        "invocation": { "modelInvocable": true, "userInvocable": true },
        "source": "bundled",
        "provider": "dsh-office"
      }
    ]
  }
}
```

`?refresh=1` запускает пересборку; первый запрос после старта ждёт её до 8 секунд,
дальше ответ идёт из кэша мгновенно.

`GET /plugin/skills/file?path=<абсолютный путь>` отдаёт
`{ ok, path, content, truncated }`. Читаются только файлы `.md`, у которых в пути
есть каталог `skills`; переходы `..` отклоняются.

`GET /plugin/skills/item?name=<kebab-case>` отдаёт
`{ ok, name, path, provider, content, truncated }` из реестра скиллов - для тех
скиллов, у которых нет файла на диске. Имя проверяется по шаблону
`^[a-z0-9]+(-[a-z0-9]+)*$`.

## Ограничения

- Маршруты `webServer` не аутентифицированы. На loopback это нормально, при
  привязке к внешнему адресу - нет.
- Запасной каталог не содержит файловых скиллов: у хоста нет агента. Полный
  список даёт только RPC сессии.
- Клиентская половина не получает конфигурацию (DSH создаёт клиентские записи без
  неё), поэтому все настройки живут в строке загрузчика.
- Тексты интерфейса русские и не проходят через клиентскую локаль; так же сделано
  в соседнем `dsh-mcp-status`.
